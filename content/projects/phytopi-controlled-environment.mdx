# Project overview

PhytoPi is a team project for monitoring and controlling a plant-growing environment. I contributed to the project as part of the team. The system connects a Raspberry Pi controller, local sensor storage, cloud synchronization, and a Flutter dashboard.

## System architecture

- **C controller on Raspberry Pi:** manages the device-side sensor and control logic.
- **SQLite sensor persistence:** stores readings locally before synchronization.
- **Supabase batch synchronization:** connects local sensor data with the cloud backend.
- **Flutter / Dart dashboard:** includes authentication and sensor charts.
- **Python camera and AI integration:** includes an Ollama/Moondream path, optional PlantNet integration, and a stub fallback.

## Engineering context

Local persistence and batch synchronization connect the device and cloud portions of the system. The dashboard presents the data, while camera and AI integrations provide a separate path for plant-image analysis.

This case study describes the team's implementation. Individual subsystem ownership, live AI accuracy, and hardware validation results are not established here.
