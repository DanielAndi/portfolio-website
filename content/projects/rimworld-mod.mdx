# Project overview

Debt Collector is a mod for the colony-simulation game **RimWorld**. It adds a debt system: a colony can borrow silver from any friendly faction through the comms console, then has to keep up with interest payments or deal with the consequences.

It is published on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3655840723) and supports RimWorld 1.4, 1.5 and 1.6. When I checked the Workshop page in November 2026, it showed 130 current subscribers.

## What it does

- **Loans from several factions at once.** Any faction with goodwill of zero or more can lend, and each one tracks its own debt.
- **Interest on a schedule.** Each loan has periodic interest payments. Missing one adds a late fee and penalty interest.
- **Collections raid.** Miss too many payments and the creditor sends a hostile raid to settle the debt by force.
- **Tribute.** After a forced collection the colony is locked out of borrowing until it pays tribute.
- **Debt Ledger.** One dialog lists every debt with its status, what is owed and when the next payment is due, with buttons to pay.
- **Safe removal.** The ledger can clear all debt state before the mod is removed, so the save still loads without it.

## How it is built

- **C# assembly** built against the game with .NET Framework 4.8, organized into the debt contracts and world-level state, the comms-console component and ledger dialog, the raid incident, settings, and the Harmony patches.
- **Harmony patches** hook the mod into the game's own code without replacing it, including how the debt state is saved and loaded.
- **XML defs and patches** add the raid incident and attach the loan controls to the comms console.
- **Mod settings** expose the interest rate, payment interval, late penalty and missed-payment fee.

## Testing

Testing is manual, in the game's developer mode. The mod adds its own debug actions, such as forcing interest to come due or starting the collections raid, and the repository's README has a step-by-step checklist that covers borrowing, paying interest, missed payments, the raid, tribute and removal.
